# Frontend Foundations

Este repositório reúne meus estudos, exercícios, desafios e projetos voltados à consolidação e ao aprofundamento dos conhecimentos em desenvolvimento Front-end.

Embora eu já tenha experiência profissional com desenvolvimento web e já tenha realizado cursos na área, decidi revisitar HTML, CSS e JavaScript desde os fundamentos para fortalecer meu domínio técnico, preencher possíveis lacunas e desenvolver mais autonomia na construção de interfaces.

Após consolidar a base, os estudos avançarão para TypeScript, React, Next.js, Tailwind CSS e outras ferramentas do ecossistema Front-end.

Não se trata de começar a programar do zero, mas de reconstruir e fortalecer conhecimentos para evoluir com mais segurança e profundidade.

---

## Objetivo do repositório

Este repositório foi criado para registrar minha evolução no desenvolvimento Front-end, desde os fundamentos até tecnologias, bibliotecas e frameworks utilizados no mercado.

Os principais objetivos são:

- Consolidar os conhecimentos de HTML, CSS e JavaScript
- Compreender cada conceito com mais profundidade
- Melhorar minha lógica de programação e resolução de problemas
- Desenvolver interfaces responsivas e acessíveis
- Criar códigos mais organizados, legíveis e reutilizáveis
- Desenvolver projetos sem depender excessivamente de ferramentas automáticas
- Evoluir em TypeScript, React, Next.js e Tailwind CSS
- Conhecer bibliotecas e ferramentas relevantes para Front-end
- Desenvolver aplicações completas no lado do cliente
- Construir uma base sólida para minha evolução profissional

## Metodologia de estudo

Durante o processo, procuro seguir estas etapas:

1. Estudar o conceito
2. Compreender sua finalidade
3. Escrever o código manualmente
4. Testar diferentes possibilidades
5. Resolver exercícios sem consultar respostas prontas
6. Identificar e corrigir erros
7. Refatorar o código
8. Registrar os principais aprendizados
9. Aplicar o conhecimento em desafios
10. Criar projetos práticos

O objetivo não é apenas assistir às aulas, copiar códigos ou concluir conteúdos, mas compreender como cada parte funciona e conseguir aplicá-la de forma autônoma.

---

## Uso de Inteligência Artificial

A Inteligência Artificial será utilizada como ferramenta de apoio e aceleração, não como substituta do aprendizado e do raciocínio técnico.

Pretendo utilizar IA principalmente para:

- Revisar códigos já desenvolvidos
- Esclarecer dúvidas específicas
- Comparar diferentes soluções
- Identificar pontos de melhoria
- Auxiliar em processos de debugging
- Receber explicações complementares
- Automatizar tarefas repetitivas
- Melhorar documentação e organização

Antes de utilizar IA para resolver um problema, buscarei compreender o desafio, desenvolver minha própria solução e exercitar meu raciocínio.

O objetivo é utilizar a tecnologia de forma consciente, mantendo domínio técnico sobre as soluções implementadas.

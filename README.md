# Frontend Foundations

Este repositório reúne meus estudos, exercícios e projetos voltados à consolidação dos fundamentos do desenvolvimento Front-end.

Embora eu já tenha experiência profissional com desenvolvimento web e já tenha realizado cursos na área, decidi revisitar HTML, CSS e JavaScript desde a base.

O objetivo é fortalecer meu domínio técnico, preencher possíveis lacunas de conhecimento e desenvolver mais autonomia na construção de interfaces e na resolução de problemas.

Não se trata de começar a programar do zero, mas de reconstruir e consolidar uma base técnica mais sólida.

---

## Objetivo do repositório

Este repositório foi criado para registrar minha evolução no estudo dos fundamentos de Front-end.

Os principais objetivos são:

- Consolidar os conhecimentos de HTML, CSS e JavaScript
- Compreender cada conceito com mais profundidade
- Desenvolver código sem depender excessivamente de frameworks
- Melhorar minha lógica de programação
- Praticar resolução de problemas
- Desenvolver interfaces responsivas
- Melhorar a organização e a legibilidade do código
- Criar projetos com mais autonomia
- Identificar e preencher lacunas de conhecimento
- Construir uma base sólida para React, Next.js e outras tecnologias Front-end

---

## Foco profissional

Meu foco profissional é exclusivamente o desenvolvimento Front-end.

Neste processo, pretendo aprofundar meus conhecimentos em:

- Estruturação de páginas

## Metodologia de estudo

Durante o processo de aprendizagem, procuro seguir estas etapas:

1. Estudar o conceito
2. Compreender sua finalidade
3. Escrever o código manualmente
4. Testar diferentes possibilidades
5. Identificar erros
6. Corrigir os problemas
7. Refatorar o código
8. Registrar os principais aprendizados
9. Aplicar o conhecimento em exercícios
10. Criar pequenos projetos práticos

O objetivo não é apenas assistir às aulas ou copiar códigos, mas compreender como cada parte funciona.

---

## Uso de Inteligência Artificial

A Inteligência Artificial será utilizada como ferramenta de apoio, e não como substituta do aprendizado.

Pretendo utilizar IA principalmente para:

- Revisar códigos
- Esclarecer dúvidas específicas
- Comparar possíveis soluções
- Identificar pontos de melhoria
- Auxiliar em processos de debugging
- Acelerar tarefas repetitivas
- Receber explicações complementares

Antes de utilizar IA para resolver um problema, buscarei compreender o desafio, desenvolver minha própria solução e exercitar meu raciocínio.

O objetivo é usar a tecnologia de forma consciente, mantendo domínio técnico sobre o código desenvolvido.
